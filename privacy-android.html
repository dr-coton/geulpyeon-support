글편 Android 개인정보 처리방침

운영: CodeBlack Inc. 문의: dr.coton@gmail.com 시행일: 2026년 11월 9일

이 방침은 Google Play에서 내려받는 글편 Android 앱(com.codeblack.geulpyeon)에 적용됩니다. iPhone·iPad·Mac 앱은 글편 개인정보 처리방침을 따릅니다.

요약

  • 글편에는 회원 가입·로그인 기능과 자체 앱 사용 분석 기능이 없습니다.
  • 문서 목록에는 문서 7개마다 ‘광고’ 표시가 붙은 Google 광고 카드가, 새 문서(템플릿) 목록 아래에는 배너 광고가 표시됩니다. 편집 화면에는 광고가 표시되지 않습니다.
  • 글편이 사용자가 연 문서의 내용이나 파일 이름을 운영자나 광고 회사에 보내는 일은 없습니다. 문서는 사용자의 기기 안에서 편집됩니다.
  • 사용자가 직접 선택한 서비스(Google Drive 같은 파일 제공자, 공유할 앱, 문서 속 링크, 이메일 문의 등)로 데이터가 오가는 경우에는 그 서비스가 데이터를 처리합니다.

1. 앱 안에서 처리하는 정보

정보처리 방식
사용자가 연 HWP/HWPX 문서의 내용과 파일 이름Android 시스템 파일 선택기나 다른 앱의 ‘열기’로 사용자가 고른 파일만 읽습니다. 원본의 복사본을 앱 전용 저장 공간의 문서함에 만들어 기기 안에서 편집하며, 원본 파일은 바꾸지 않습니다.
사용자가 저장한 수정본·PDF사용자가 시스템 저장 화면에서 고른 위치에 새 파일로 저장하거나, 사용자가 고른 앱으로 공유합니다.
문서함 정보문서 제목, 폴더, 태그, 즐겨찾기, 자동 보관본, 사용자가 저장한 버전을 기기 안에 보관합니다.
문서에 넣는 사진Android 사진 선택기에서 사용자가 고른 사진만 문서에 넣습니다. 사진 보관함 전체에 접근하는 권한은 요청하지 않습니다.
복사·붙여넣기 내용사용자가 복사하거나 붙여넣을 때만 시스템 클립보드를 씁니다.
  • 글편의 문서 편집 엔진은 오픈소스 rhwp를 바탕으로 하며 앱 안에 포함되어 기기에서 동작합니다. 편집 화면은 인터넷 없이 동작하며 외부 주소로 요청을 보내지 않습니다.
  • 앱에는 광고 표시를 위한 Google Mobile Ads SDK와 광고 동의를 위한 Google User Messaging Platform SDK가 포함됩니다. 자세한 내용은 2절에 있습니다.
  • 글편은 위치, 연락처, 카메라, 마이크, 저장소 전체에 대한 접근 권한을 요청하지 않습니다. 인터넷·네트워크 상태 권한과 광고 ID 권한은 광고에만 씁니다.

2. 광고

문서 목록이나 새 문서 목록이 열리면 Google Mobile Ads SDK가 광고를 요청합니다. 이때 Google이 아래 정보를 수집해 광고 표시, 광고 성과 측정, 분석, 부정 방지에 사용할 수 있습니다. 운영자는 이 정보를 직접 받지 않고, 광고 노출 수와 수익 같은 집계 보고서만 받습니다.

정보예시
기기 식별자Android 광고 ID, 앱 세트 ID 등 기기·앱 단위의 식별자
대략적인 위치IP 주소로 추정한 위치. 글편은 위치 권한을 요청하지 않습니다.
앱 활동앱 실행, 광고 노출과 탭
앱 정보와 성능비정상 종료 기록, 진단 정보
  • 문서 내용, 파일 이름, 폴더, 태그는 광고 요청에 포함되지 않습니다. 문서 목록의 광고 카드는 문서가 아니며 ‘광고’ 표시가 붙습니다.
  • 광고는 모든 연령에 적합한 등급(G)으로 제한합니다.
  • 유럽경제지역·영국 등 법에 따라 동의가 필요한 지역에서는 광고 전에 Google의 동의 화면이 표시됩니다. 선택은 앱의 앱 정보 > 광고 개인정보 설정에서 언제든 바꿀 수 있습니다.
  • 광고 ID는 기기의 설정 > 보안 및 개인정보 보호 > 개인정보 보호 > 광고(기기마다 메뉴 이름이 다를 수 있음)에서 재설정하거나 삭제할 수 있습니다. 삭제해도 광고는 표시되며, 관심사에 맞지 않는 광고가 나올 수 있습니다.
  • 인터넷에 연결되어 있지 않으면 광고는 표시되지 않고, 문서 편집은 그대로 쓸 수 있습니다.
  • Google의 정보 처리는 Google 개인정보처리방침과 Google이 파트너 사이트의 정보를 사용하는 방식을 따릅니다.

3. 사용자가 선택한 서비스로 오가는 정보

사용자의 선택데이터를 처리하는 곳
Google Drive 등 파일 제공자의 문서를 열거나 그곳에 저장해당 파일 제공자의 방침이 적용됩니다.
공유 기능으로 수정본·PDF 전송, 인쇄사용자가 고른 앱, 인쇄 서비스가 처리합니다.
문서 속 링크를 열기로 선택링크가 가리키는 웹사이트나 그 링크를 여는 앱이 접속 정보를 처리할 수 있습니다.
이메일로 문의보낸 이메일의 내용과 주소를 문의 답변에만 씁니다. 문의 해결 후 1년 이내에 삭제하며, 그 전에 삭제를 요청할 수 있습니다.
지원·개인정보 페이지 방문이 페이지는 GitHub Pages로 제공됩니다. 방문 시 GitHub가 접속 기록 같은 정보를 처리할 수 있습니다. GitHub의 개인정보 처리방침이 적용됩니다.

Google Play가 제공하는 비정상 종료·성능 보고(Android vitals)는 사용자가 기기에서 사용 및 진단 정보 공유를 켠 경우 Google이 수집해 개발자에게 집계 형태로 보여 줍니다.

4. 기기에 남는 정보와 삭제

저장 위치보호삭제 방법
문서함(문서 사본, 자동 보관본, 저장한 버전, 제목·폴더·태그)앱 전용 저장 공간. 다른 앱이 읽을 수 없고, 기기 백업·기기 간 이전에서 제외문서를 휴지통으로 옮긴 뒤 영구 삭제하면 지워집니다. 자동으로 만료되지 않습니다.
공유·인쇄용 임시 파일앱 전용 캐시Android가 저장 공간이 부족할 때 지우며, 앱 설정의 ‘캐시 삭제’로도 지울 수 있습니다.
광고 동의 선택앱 전용 저장 공간앱 정보의 광고 개인정보 설정에서 바꾸거나 앱 데이터를 지우면 삭제됩니다.
  • 앱을 삭제하거나 설정 > 앱 > 글편 > 저장공간 > 데이터 삭제를 누르면 위의 앱 전용 데이터가 모두 삭제됩니다. 사용자가 다른 위치에 저장한 수정본은 그대로 남습니다.
  • 글편에는 계정이 없어 운영자가 보관하는 사용자 데이터가 없습니다. 따라서 별도의 계정 삭제 절차가 없습니다.

5. 제3자 제공

운영자는 사용자가 연 문서나 앱 사용 정보를 받지 않으므로 이를 제3자에게 제공하지 않습니다. 2절의 광고 정보는 Google Mobile Ads SDK를 통해 Google과 광고 파트너에게 직접 전달됩니다. 이메일 문의 내용은 답변 목적 외에 제3자에게 제공하지 않습니다.

개인정보의 국외 이전

2절의 광고 정보는 광고 요청 과정에서 국외에 있는 Google로 전송될 수 있습니다. 운영자는 이 정보를 직접 받거나 보관하지 않습니다.

항목내용
이전받는 자Google LLC (문의: Google 개인정보 문의)
이전되는 국가미국 및 Google이 데이터 센터를 운영하는 국가
이전 시기와 방법문서 목록이나 새 문서 목록에서 광고를 요청할 때, 그리고 광고 동의 상태를 확인할 때 인터넷으로 전송
이전되는 항목기기 식별자(광고 ID 등), 대략적인 위치(IP 주소 기반), 앱 활동, 앱 정보와 성능

거부 방법과 영향기기 설정에서 광고 ID를 삭제하면 광고 ID는 전송되지 않습니다. 동의가 필요한 지역에서는 앱 정보의 광고 개인정보 설정에서 동의를 거부할 수 있습니다. 그 밖의 광고 정보 전송을 원하지 않으면 기기를 인터넷에 연결하지 않은 상태로 사용할 수 있으며, 이때도 문서 편집 기능은 모두 쓸 수 있고 광고만 표시되지 않습니다.
