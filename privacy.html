글편 개인정보 처리방침

운영: CodeBlack Inc. 문의: dr.coton@gmail.com 시행일: 2026년 10월 22일

요약

  • 글편은 회원 가입·로그인, 광고, 앱 사용 분석, 추적 기능이 없습니다.
  • 글편이 사용자가 연 문서의 내용이나 파일 이름을 운영자에게 보내는 일은 없습니다. 문서는 사용자의 기기 안에서 편집됩니다.
  • 사용자가 직접 선택한 서비스(파일 앱의 저장 위치, iCloud Drive 같은 파일 제공자, 문서 속 링크, 이메일 문의 등)로 데이터가 오가는 경우에는 그 서비스가 데이터를 처리합니다.

1. 앱 안에서 처리하는 정보

정보처리 방식
사용자가 연 HWP/HWPX 문서의 내용과 파일 이름원본의 복사본을 앱 전용 저장 공간에 만들어 기기 안에서 편집합니다. 원본 파일은 바꾸지 않습니다.
사용자가 저장한 수정본사용자가 고른 위치에 새 파일로 저장합니다.
복구 사본저장하지 않은 편집 내용을 기기 안에 보관합니다. 복구 사본에는 원본 파일 이름과 시각이 함께 기록됩니다.
문서 비밀번호사용자가 입력한 경우 그 문서를 열거나 저장할 때 기기 안에서만 씁니다. 비밀번호는 저장하지 않으며, 암호 문서는 복구 사본을 만들지 않습니다.
복사·붙여넣기 내용사용자가 복사하거나 붙여넣을 때만 시스템 클립보드를 씁니다.
  • 글편의 문서 편집 엔진은 오픈소스 rhwp를 바탕으로 하며 앱 안에 포함되어 기기에서 동작합니다.
  • 광고·분석·추적용 SDK는 포함하지 않습니다.
  • 글편은 위치, 연락처, 사진 보관함, 카메라, 마이크, 광고 식별자에 대한 접근 권한을 요청하지 않습니다.

2. 사용자가 선택한 서비스로 오가는 정보

사용자의 선택데이터를 처리하는 곳
파일 앱에서 iCloud Drive나 다른 파일 제공자의 문서를 열거나 그곳에 저장해당 파일 제공자(예: Apple iCloud)의 방침이 적용됩니다.
문서 속 링크를 열기로 선택링크가 가리키는 웹사이트나 그 링크를 여는 앱이 접속 정보를 처리할 수 있습니다.
파일 앱·공유 기능으로 수정본 전송사용자가 고른 앱이나 서비스가 처리합니다.
이메일로 문의보낸 이메일의 내용과 주소를 문의 답변에만 씁니다. 문의 해결 후 1년 이내에 삭제하며, 그 전에 삭제를 요청할 수 있습니다.
지원·개인정보 페이지 방문이 페이지는 GitHub Pages로 제공됩니다. 방문 시 GitHub가 접속 기록 같은 정보를 처리할 수 있습니다. GitHub의 개인정보 처리방침이 적용됩니다.

Apple이 제공하는 충돌 보고와 앱 분석은 사용자가 기기 설정에서 개발자와 공유하기로 한 경우에만 Apple을 통해 전달됩니다. 이 정보는 Apple이 수집하고 처리합니다.

3. 기기에 남는 정보와 삭제

저장 위치보호삭제 방법
작업 복사본iOS 파일 보호 적용, 기기 백업 제외다른 문서를 열면 이전 복사본을 정리합니다. 앱이 비정상 종료되면 남을 수 있습니다.
저장 준비용 임시 파일iOS 파일 보호 적용, 기기 백업 제외저장을 마치거나 취소하면 삭제합니다.
복구 사본iOS 파일 보호 적용, 기기 백업 제외앱의 복구 목록에서 문서별로 삭제합니다. 자동으로 만료되지 않습니다.
편집 화면의 브라우저 저장소영구 저장소를 쓰지 않습니다앱을 종료하면 사라집니다.
  • 앱을 삭제하면 위의 앱 전용 데이터도 함께 삭제됩니다. 사용자가 다른 위치에 저장한 수정본은 그대로 남습니다.
  • 앱 ID가 다른 이전 개발용 앱이 기기에 남긴 데이터는 글편으로 자동 이관하지 않습니다. 그 데이터는 해당 앱을 삭제하면 함께 지워집니다.
  • 같은 앱 ID로 설치된 개발 빌드를 App Store 버전으로 업데이트하면, 기존 앱 전용 데이터(작업 복사본·복구 사본 등)가 그대로 남을 수 있습니다. 필요하면 복구 목록에서 지우거나 앱을 삭제해 주세요.
